# Calcolon ONLINE（カルコロン オンライン）

2〜4人で遊べる、Firebase + GitHub Pages 用の静的Webサイトです（ビルド不要）。

## セットアップ
1. **Firebase**: プロジェクトを作成 → ①Authentication で「匿名」を有効化 ②Realtime Database を作成
   → ③「ルール」に `database.rules.json` の中身を貼り付けて公開 → ④ウェブアプリを登録して表示される `firebaseConfig` を `js/firebase-config.js` に貼る
   （`databaseURL` も必須です）。
2. **GitHub Pages**: このフォルダの中身をリポジトリのルートに置き、Settings → Pages で `main` ブランチの `/ (root)` を公開。
3. 公開URLを開く → 名前を入れて「部屋を作る」→ 4文字の部屋コードを友達に伝える。
4. Firebaseの「承認済みドメイン」に `<ユーザー名>.github.io` を追加してください（Authentication → 設定）。

## 仕組み
- **ホスト（部屋を作った人）のブラウザがゲーム進行役**です。山札・手札・ルール判定はホスト端末で行い、公開情報は `pub`、各自の手札は `hands/<uid>` に配信します（手札はルール上、本人とホストだけが読めます）。
- ホストが閉じる/リロードすると進行が止まります。ホストがページを開き直せば `private` から復元して再開します（同じブラウザ・同じ端末で）。
- 手札の秘匿は簡易的です（ホスト本人は開発者ツールで全員の手札を見ようと思えば見られます）。

## ルールの解釈（指定のなかった部分の仮置き）
- 左隣 ＝ 手番順で次の人。式は通常の演算順序。1/10は分数で厳密計算。ボウ2枚以上持つと括弧を使える。
- コンプリート ＝ 結果が **0以上の整数で下一桁が0**（負の結果は不可）。デビルゼロは数字の0として使える。
- 手札が3枚以下（フレイムアローの被害後）の番は「1枚引くだけで捨てずに終了」。
- ロブは、捨て札が出るたび全員に「ロブ猶予」（ロビーで設定、既定3.5秒）が付く。複数人が同時にロブしたら、捨てた人の次の順番に近い人が優先。ボウ・トレード・効果で使ったフレイムアロー・押し付けたデビルゼロはロブ不可。
- ラストドロー中は特殊効果なし（ボウは公開して引き直し、デビルゼロは通常の捨てが可能）。
- フレイムアロー: 指定したカードを **全員の手札から1枚ずつ**（使用者含む）消す。ボウを1枚消費。
- トレード: デビルゼロは引くことも渡すこともできない。相手の手札の位置は毎回シャッフルされるので、ババ抜き式に伏せ札から選ぶ。
- リベリオンの「ドローの代わりのトレード」は、交換して手番終了（捨てない）。
- 同値で、キングがいない同点の勝者は全員勝利。次のデュエルは前回の勝者から。

# Calcolon ONLINE（カルコロン オンライン）

2〜4人で遊べる、Firebase + GitHub Pages 用の静的Webサイトです（ビルド不要）。

## セットアップ
1. **Firebase**: プロジェクトを作成 → ①Authentication で「匿名」を有効化 ②Realtime Database を作成
   → ③「ルール」に `database.rules.json` の中身を貼り付けて公開 → ④ウェブアプリを登録して表示される `firebaseConfig` を `js/firebase-config.js` に貼る
   （`databaseURL` も必須です）。
2. **GitHub Pages**: このフォルダの中身をリポジトリのルートに置き、Settings → Pages で `main` ブランチの `/ (root)` を公開。
3. 公開URLを開く → 名前を入れて「部屋を作る」→ 4文字の部屋コードを友達に伝える。
4. Firebaseの「承認済みドメイン」に `<ユーザー名>.github.io` を追加してください（Authentication → 設定）。

## 仕組み
- **ホスト（部屋を作った人）のブラウザがゲーム進行役**です。山札・手札・ルール判定はホスト端末で行い、公開情報は `pub`、各自の手札は `hands/<uid>` に配信します（手札はルール上、本人とホストだけが読めます）。
- ホストが閉じる/リロードすると進行が止まります。ホストがページを開き直せば `private` から復元して再開します（同じブラウザ・同じ端末で）。
- 手札の秘匿は簡易的です（ホスト本人は開発者ツールで全員の手札を見ようと思えば見られます）。

## 遊び方メモ（v2）
- **手札は自分で並べ替えます**（PCはドラッグ、スマホ/PCとも カードを選んで ◀ ▶）。左から「数字・記号・数字・記号・数字」の順に並べて式が完成すると、初めて「アタック！」が出ます。
- ボウを2枚以上持っていると「括弧」ボタンが出て、( 1〜3枚目 ) または ( 3〜5枚目 ) を選べます。
- ラストドローでは、1枚捨てたあと手札を並べて「確定」を押します（並びが式になっていなければバースト）。
- **アタックが発生**すると中央にカットインが入り、終わってから全員がラストドローします。
- **トレード**: 相手を指名 → 相手が手札を並べ替えて「確定」 → 自分の渡すカードと、相手の伏せ札から引くカードを選ぶ。
- **デビルゼロ**はドローしても何も起きず、捨てて押し付けた瞬間からデビルハンドが付きます。押し付けられた人はすぐ手札から1枚捨て、そこから次の手番になります。押し付けられたデビルゼロは、ラストドローでも捨てられません（自分で引いたものは捨てられます）。
- **手札公開**: ラストドロー後、キングから順（手番順）に手札が公開され、点数やバーストが見えてからリザルトが出ます。
- **ボウ**は右下の自分の場に表向きで並び、2枚目は上下反転して「 ) 」になります。
- **CPU対戦**: ロビーで「＋ CPUを追加」（最大で合計4人）。CPUの操作はホスト端末で動きます。

## 得点ルール・決勝ルール
- **最終デュエル**は勝者の得点が2倍（減点は2倍にしません）。
- **0勝利**: 勝者の数値が0だった場合、その人が次のデュエルも勝つと、その得点が直前のデュエルにも加算されます（遡及ぶんは2倍にしません）。負けやバースト等なら遡及なし。2連続で0勝利した場合、2回目は100点換算（前回にも+100）。
- **ダブルスコア**: 直前の勝者と同じ点数で勝つと、その得点をもう1回加算。最終デュエルと重なると「獲得×2 ＋ 上乗せ×1」＝3倍。
- **決勝ルール**（ロビーで選択・2人専用）: 手札は通常6枚、決着は7枚（数字4＋記号3）。括弧は範囲の候補が増えます。

## ルールの解釈（指定のなかった部分の仮置き）
- 左隣 ＝ 手番順で次の人。式は通常の演算順序。1/10は分数で厳密計算。
- コンプリート ＝ 結果が **0以上の整数で下一桁が0**（負の結果は不可）。デビルゼロは数字の0として使える。
- 手札が3枚以下（フレイムアローの被害後）の番は「1枚引くだけで捨てずに終了」。
- ロブは、捨て札が出るたび全員に「ロブ猶予」（ロビーで設定、既定3.5秒）が付く。ロブのボタンは「並べ替えれば完成する」時に押せ、ロブアタックの式は自動で組まれます。複数人が同時にロブしたら、捨てた人の次の順番に近い人が優先。ボウ・トレード・効果で使ったフレイムアロー・押し付けたデビルゼロはロブ不可。
- ラストドロー中は特殊効果なし（ボウは公開して引き直し、デビルゼロは通常の捨てが可能）。
- フレイムアロー: 指定したカードを **全員の手札から1枚ずつ**（使用者含む）消す。ボウを1枚消費。フレイムアロー自身は指定不可。
- トレード: 押し付け済みのデビルゼロは引けない。自分のデビルゼロは渡せない。
- リベリオンの「ドローの代わりのトレード」も同じ手順で、交換して手番終了（捨てない）。
- 同値で、キングがいない同点の勝者は全員勝利。次のデュエルは前回の勝者から。
